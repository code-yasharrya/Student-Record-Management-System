
# Assignment 1: Mini Project
# Student Record Management System

## 1. Introduction
The Student Record Management System is a console-based Python application designed to manage student information.

## 2. Objectives
- Learn Python data types and variables.
- Understand conditional statements and loops.
- Implement functions.
- Handle errors using exception handling.
- Store data using file handling.

## 3. Features
- Add student records.
- View all student records.
- Search student records.
- Update student information.
- Delete student records.
- Store records in a JSON file.

## 4. Concepts Used

### Data Types and Variables
Strings are used for student names, IDs, and courses. Integers are used for age.

### Conditional Statements
If, elif, and else statements are used to select menu operations.

### Loops
While and for loops are used to repeat operations and process records.

### Functions
Different functions are created for adding, viewing, searching, updating, and deleting records.

### Exception Handling
Try and except blocks handle invalid inputs and file-related errors.

### File Handling
JSON files are used to save and retrieve student information.

## 5. Software Requirements
- Python 3
- Visual Studio Code
- Windows Operating System

## 6. Program Execution
Run the application using:

python main.py

The menu appears and the user can select an operation.

## 7. Conclusion
This project helped demonstrate the practical use of Python programming concepts by developing a working Student Record Management System.
