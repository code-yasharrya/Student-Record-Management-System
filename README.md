
# Student Record Management System

## Project Description
This is a Python-based Console Record Management Application. It allows users to manage student records using a simple menu-driven interface.

## Features
- Add Student Record
- View All Student Records
- Search Student Record
- Update Student Record
- Delete Student Record
- Save records permanently using JSON file storage
- Exception handling for invalid inputs

## Technologies Used
- Python 3
- JSON
- File Handling
- Functions
- Loops and Conditional Statements
- Exception Handling

## How to Run

1. Install Python 3.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

```bash
python main.py
```
